# Моё питание — персональное PWA

## Запуск
1. Распакуйте архив.
2. Создайте публичный репозиторий GitHub, например `moe-pitanie`.
3. Загрузите в корень репозитория все 4 файла: `index.html`, `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png`.
4. В Settings → Pages выберите Deploy from a branch, ветку `main`, папку `/ (root)` и сохраните.
5. Откройте опубликованный адрес `https://ВАШ_ЛОГИН.github.io/moe-pitanie/` в Safari на iPhone.
6. Нажмите «Поделиться» → «На экран Домой».

Данные хранятся в localStorage конкретного браузера/установленной копии. Не рассчитывайте на автоматическую синхронизацию между Safari и установленной PWA. Регулярно сохраняйте резервную копию в разделе «Данные».

КБЖУ приблизительные, особенно для приготовленных блюд; это не медицинский инструмент. Конструктор масштабирует ингредиенты математически, но не генерирует AI-рецепты.

GitHub Pages — публичный хостинг: код и исходные рецепты доступны другим людям. Ваш личный дневник не загружается в GitHub, а хранится локально на устройстве.
