Моё питание v2 — автономный PWA-дневник.
Загрузка: загрузите файлы из архива в корень репозитория GitHub Pages moe-pitanie, предварительно сохранив резервную копию прежних файлов. Публикация занимает несколько минут; на iPhone откройте адрес сайта и при необходимости обновите приложение.
Важно: v2 использует отдельное хранилище moe_pitanie_v2 и не переносит данные из старой версии автоматически. Сначала экспортируйте старые данные, если они важны; формат резервной копии может отличаться.
Поиск продуктов требует интернет. Данные Open Food Facts могут быть неполными, всегда проверяйте КБЖУ.
Камера сканирует штрихкод только в браузерах с BarcodeDetector; на iOS может потребоваться ручной ввод кода.
Напоминания в v2 работают только пока приложение открыто; фоновые push-уведомления отсутствуют.
Данные хранятся в localStorage на устройстве, поэтому регулярно используйте экспорт резервной копии.
